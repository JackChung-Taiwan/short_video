# 協會老師短影音拍攝指引

美語 ESL、Minecraft、Roblox、ScratchJr、OctoStudio 的素材收集網站。

## 內容

- 三類素材：老師教什麼、孩子怎麼做、最後做出什麼。
- 五門課的拍攝角度、操作過程、成果與拍攝順序。
- 可依課程篩選的指引與可截圖的手機一頁版。
- 八項 Checklist，透過 localStorage 保留同一瀏覽器的進度，支援重設。
- 素材命名與可複製的交接格式。
- Shorts 行銷目標、分階段成效指標與 30 秒剪輯示例。
- YouTube 官方說明來源，查核日期 2026-09-24。

## 使用

`index.html` 是完整單檔網站，不需要建置、套件或外部字型。可直接開啟；使用 HTTPS 網站可完整使用複製功能。瀏覽器若禁止儲存或複製，頁面會顯示替代操作提示。

## GitHub Pages

在本儲存庫 Settings → Pages → Build and deployment 選擇：

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

部署完成後，請使用 Pages 設定頁提供的網站網址。本檔案不代表 Pages 已完成啟用。

## 維護

直接編輯 `index.html` 的 HTML、CSS 或 JavaScript。課程內容為靜態 HTML；關閉 JavaScript 仍能展開與閱讀。列印時會暫時展開所有課程，列印結束後還原原本篩選狀態。

本站不收集影片、個資或成效分析資料，也沒有後端。Checklist 僅儲存在使用者的瀏覽器。影片原始檔請另行交到協會指定資料夾。

行銷效益是規劃目標，不是流量或招生保證；拍攝秒數是素材建議，不是平台長度限制。
