重點工具｜老師手機拍攝清單

上課前打開，拍完就勾選。

這堂課的素材

已完成 0 / 8
01
拍穩、拍清楚

雙手持機；先對焦螢幕再錄。避開反光、快速甩動與反覆放大縮小。

02
每段留頭、留尾

動作前後各多留約 1 秒。美語靠近發聲者，拍完回放一次確認收音。

03
操作與成果各有一段

程式課可另外收螢幕錄影，保留完整作品；直式手機素材照常拍攝。

04
保留原始檔

不加字幕、音樂、濾鏡或轉場。交到協會指定資料夾，避免通訊軟體壓縮畫質。

05
讓孩子自然參與

優先拍手部、背影與作品。可辨識學生或使用訪談前，確認校方與家長授權；避開姓名、帳號與私人訊息。

補充一｜拍攝方法

一堂課，收齊三種畫面。

先選一個小任務，再拍下教學、操作與結果。老師負責收素材，後續由協會統一剪輯。

① 教學示範

老師教什麼

建議 2 段
  • 拍什麼：指向一個積木、示範一項功能，或出示一張圖卡。
  • 怎麼拍：老師的手勢＋螢幕／教材一起入鏡，鏡頭固定 5–10 秒。
  • 收一句話：「今天我們用＿＿，讓＿＿。」

讓觀眾知道今天的學習任務。

② 操作過程

孩子怎麼做

建議 3–5 段
  • 拍什麼：拖積木、改數字、按執行、指圖卡、討論與修正。
  • 怎麼拍：從肩膀後方拍「手＋畫面」；每個動作各錄 5–15 秒。
  • 多留一段：發現問題 → 修改 → 再試一次。

讓觀眾看懂孩子正在做什麼。

③ 課堂成果

最後做出什麼

建議 1–3 段
  • 拍什麼：動畫播放、機關運作、實際遊玩，或完成美語任務。
  • 怎麼拍：下課前留 1–2 分鐘；固定或慢移鏡頭，錄 5–15 秒。
  • 收完整動作：按下開始 → 畫面產生結果。

留下能看見成果的結尾。

補充二｜課程範例

選一門課，照著拍就好。

每次只拍一項功能或一句美語。點開課程，查看角度、動作與成果。

美語 ESL從聽懂問題，到完成小任務

① 老師教什麼

老師拿出 Apple 圖卡，示範「What is this?」；或示範一個 Phonics 音。拍到圖卡與口語提示。

② 孩子怎麼做

從側後方拍孩子找圖卡、指答案、跟讀或兩人對話；保留孩子思考與回應的時間。

③ 最後做出什麼

收一段完整問答：「What is this?」「It's an apple.」也可以拍配對成功，以課堂實際表現為準。

拍攝順序：示範 Apple → 孩子找圖卡 → 指出圖片並回答
收音優先：靠近發聲者，保留問句和回答。
Minecraft程式執行，讓作品一步步出現

① 老師教什麼

老師指向 MakeCode 的一個積木，示範 Agent 移動或放置方塊。收進手勢與螢幕：「用重複積木，蓋出一面牆。」

② 孩子怎麼做

從肩後拍拖積木、改次數、按執行；若位置不對，補拍修改數值與再次測試，各動作分段錄。

③ 最後做出什麼

慢慢巡覽建築，或錄 Agent 放置方塊、紅石機關運作。保留執行後看見結果的片段。

拍攝順序：示範 Agent → 修改程式與測試 → 蓋出作品
拍建築時固定視角或慢慢移動；機關另收一段運作畫面。
Roblox從 Studio 設定，到 Play 實際遊玩

① 老師教什麼

示範新增 Part、設定顏色，或說明碰到金幣加分的程式。選一個功能近拍：「碰到金幣，分數會增加。」

② 孩子怎麼做

拍孩子建物件、改參數、寫程式與按 Play；遇到 Bug 時，收一段老師提示與孩子修正。

③ 最後做出什麼

在 Play 模式實際操作：碰金幣後分數增加、門打開或角色變色。把觸發前後都錄到。

拍攝順序：教碰撞功能 → 孩子修改並測試 → 碰到金幣成功加分
成果拍實際遊戲畫面；角色與分數 UI 盡量同時入鏡。
ScratchJr拖一拖積木，故事開始動起來

① 老師教什麼

近拍老師拖入綠旗與藍色移動積木，再按綠旗：「接上這個積木，小貓就會往右走。」

② 孩子怎麼做

從側上方拍手指拖積木、調整順序、按綠旗；孩子試不同數值時，可各拍一段。

③ 最後做出什麼

讓動畫從頭播放一次，例如小貓走過來、說 Hello、另一個角色回應或換場景。

拍攝順序：示範移動 → 孩子排列積木 → 動畫播放
避開平板反光；操作後移開手指，讓觀眾看清結果。
OctoStudio把身體動作，接到畫面反應

① 老師教什麼

示範課堂設定好的搖晃或傾斜事件：「今天讓平板搖一搖，角色就會跳舞。」拍到動作與畫面變化。

② 孩子怎麼做

拍孩子設定事件與動作，再拿起平板測試。從側前方同時拍到手、裝置與螢幕。

③ 最後做出什麼

完整收一段「搖一搖 → 角色跳舞」，或「傾斜 → 角色移動」，依實際程式呈現。

拍攝順序：示範互動 → 孩子設定並測試 → 動作觸發效果
